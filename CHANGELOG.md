# История версий FastScreen

## 1.0.5 — 2026-10-26

- Повреждённые или недоступные настройки безопасно заменяются значениями по умолчанию при чтении.
- Чтение настроек ограничено: папка — 4 КиБ, горячие клавиши — 1 КиБ. Некорректный UTF-8 и недопустимые пути отклоняются.
- Папка и горячие клавиши сохраняются через уникальные временные файлы с атомарной заменой.

## 1.0.4 — 2026-10-26

- Поиск собственных системных P/Invoke ограничен каталогом System32.
- Проводник запускается по абсолютному пути из системной папки Windows без поиска через PATH и Shell.
- Добавлены проверки политики загрузки DLL и команды открытия папки с пробелами в пути.

## 1.0.3 — 2026-10-26

- После успешного сохранения скриншота проигрывается выбранный звук №7 — мягкий колокольчик.
- Звук встроен в EXE, проигрывается асинхронно и не требует внешних файлов или интернета.
- При отмене выделения и ошибке сохранения звука нет. Ошибка аудио не отменяет сохранение PNG.

## 1.0.2 — 2026-10-26

- Крупное ярко-синее перекрестие с белой обводкой для выделения области.
- Подготовлены три звуковых варианта для выбора. Воспроизведение при сохранении пока не включено.

## 1.0.1 — 2026-10-26

- Только один экземпляр FastScreen для пользователя в текущем сеансе Windows, независимо от имени EXE и версии.
- Повторный запуск возвращает существующее окно из трея. Во время выделения области открытие откладывается до завершения или отмены съёмки.
- После аварийного завершения блокировка автоматически освобождается Windows.

## 1.0.0 — 2026-10-26

Первый выпуск с номером версии:

- Снимок всего экрана или выделенной области с сохранением PNG локально.
- Стартовый экран и интерфейс в стилистике Windows 11.
- Работа из трея и настраиваемые глобальные горячие клавиши.
- Версия в окне программы, значке трея и свойствах исполняемого файла.
