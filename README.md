# FastScreen

Простая программа для Windows 10/11. Запустите **FastScreen-1.0.4.exe**.

Обычный запуск допускает только один экземпляр FastScreen для пользователя в текущем сеансе Windows. Повторный запуск возвращает работающее окно, включая скрытое в трее. Блокировка не зависит от имени или расположения EXE. Во время съёмки запрос открытия откладывается до её завершения; после сбоя блокировка не остаётся навсегда. Старые версии до 1.0.1 не поддерживают этот механизм — их нужно закрыть через меню трея.

## Версии

Номер хранится в одном файле `VERSION` в формате `MAJOR.MINOR.PATCH`. Например: `1.0.1` — исправление, `1.1.0` — новая возможность, `2.0.0` — несовместимые изменения. Для нового выпуска измените `VERSION`, дополните `CHANGELOG.md` и запустите сборку. Повторная сборка не увеличивает номер автоматически.

Сборка создаёт `FastScreen-<версия>.exe` и записывает этот же номер в свойства файла и интерфейс. В свойствах Windows версия файла имеет четыре части (`1.0.0.0`), версия продукта — три (`1.0.0`). Настройки и папка скриншотов общие для всех версий.

## Использование

При запуске появляется стартовый экран. Кнопка **Создать скриншот** открывает рабочий интерфейс; разделы **Создать скриншот** и **Горячие клавиши** доступны в верхней панели.

Интерфейс выполнен в светлой стилистике Windows 11: голубоватые поверхности, скруглённые карточки, синий акцент, подсветка наведения и клавиатурного фокуса. На Windows 11 системная рамка использует скругление и цвет заголовка; на Windows 10 остаётся стандартная рамка. Фон рисуется локально, без загрузки изображений из интернета.

- **Весь экран** — захватывает все подключённые мониторы одним изображением.
- **Выделить область** — зажмите левую кнопку мыши, выделите прямоугольник и отпустите. Esc или правая кнопка мыши отменяют съёмку.
- Снимок автоматически сохраняется в PNG. Окно программы скрывается перед захватом.
- Папка по умолчанию: `%LOCALAPPDATA%\LocalScreenshot\Screenshots`. Кнопка **Изменить…** позволяет выбрать другую папку, а **Открыть папку** показывает сохранённые снимки.
- **Открыть последний снимок** открывает PNG в стандартной программе просмотра.
- Глобальные сочетания по умолчанию: **Ctrl+Shift+F** — весь экран, **Ctrl+Shift+A** — область. Они работают из других программ и из трея, пока приложение запущено.
- В разделе **Горячие клавиши** выберите поле, нажмите своё сочетание и сохраните. Требуется Ctrl или Alt; можно добавить Shift. Для двух режимов нужны разные сочетания. Если сочетание занято, изменения не применятся. F12 зарезервирована Windows и не предлагается.
- **В трей**, сворачивание и крестик скрывают окно. Двойной щелчок по значку возвращает его. Меню значка позволяет сделать снимок или настроить клавиши. **Выйти** в меню полностью закрывает приложение и освобождает сочетания.
- Снимок из трея сохраняется без открытия основного окна; отмена выделения также оставляет программу в трее.

Программа не использует интернет, серверы, аккаунты или телеметрию. UNC-пути и сетевые диски не принимаются. Выбранная папка запоминается в `%LOCALAPPDATA%\LocalScreenshot\folder.txt`, горячие клавиши — в `hotkeys.txt` рядом с ним. Приложение не добавляет себя в автозагрузку.

Если Windows перенаправляет папку «Изображения» в OneDrive или другой сервис синхронизации, выберите обычную локальную папку: сторонний клиент может синхронизировать её содержимое независимо от программы.

Курсор мыши в снимок не включается. Защищённое видео и системный защищённый рабочий стол могут не захватываться.

## Сборка из исходников

Требуется .NET Framework 4.8 (входит в современные Windows), дополнительные пакеты не нужны.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

Проверка единственного экземпляра выполняется отдельно: `powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\run-single-instance.ps1`. Она проверяет конкурирующие процессы, сигнал активации, штатное освобождение и восстановление после аварийного завершения тестового процесса. Диагностические режимы `--self-test`, `--logic-test`, `--render-test` выполняются отдельно от блокировки обычного приложения.

Если запущенная версия блокирует перезапись файла, завершите её через меню трея → **Выйти** или соберите отдельный файл: `powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -OutputPath C:\полный\путь\FastScreen-next.exe`.

Для самопроверки запустите `FastScreen-1.0.4.exe --self-test C:\полный\путь\report.txt` и дождитесь завершения процесса. Проверка делает снимок рабочего стола, проверяет PNG и удаляет временные изображения, оставляя текстовый отчёт. `--logic-test` с тем же аргументом проверяет настройки, реальные регистрации глобальных клавиш, обработку конфликтов, переходы экранов и трей без захвата рабочего стола. Проверки сохраняют три изображения интерфейса рядом с отчётом. Запускайте их из отдельной папки в обычном сеансе Windows.

`--render-test` с путём к отчёту отдельно проверяет отрисовку трёх экранов с включёнными визуальными стилями Windows и отсутствие чёрных прямоугольных краёв у кнопок. Фон и форма кнопки рисуются целиком одним проходом, чтобы стандартная прямоугольная отрисовка Windows не проступала по краям.

При выделении области используется крупное синее перекрестие с белой обводкой. Курсор не попадает в сохранённый снимок: изображение рабочего стола захватывается до начала выделения.

Восемь пробных звуков можно создать локально с Python 3: `python tools/generate-sounds.py`. WAV-файлы появятся в `obj/sound-previews`. Варианты 04 и 05 имеют мягкую атаку и повышенную на 3,5 дБ громкость относительно первых проб; 06–08 — дополнительные мягкие сигналы. В версии 1.0.3 подключён вариант 07 — мягкий колокольчик. Он звучит после успешного сохранения PNG, в том числе при съёмке из трея. При отмене выделения или ошибке записи звука нет. WAV встроен в EXE; сбой звука не мешает сохранению снимка. Для запуска самой программы Python не нужен.

В версии 1.0.4 системные DLL для собственных P/Invoke ищутся только в System32. Кнопка «Открыть папку» запускает Проводник по абсолютному пути из системной папки Windows, без поиска исполняемого файла через PATH.
